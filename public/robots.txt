# Tape — crawler rules.
#
# Public, indexable: homepage, preset dashboards, individual chart pages,
# about. These are the URLs we want search engines to surface.
#
# Hidden from indexing: user accounts, saved dashboards (each one is
# specific to its owner), the composer (a tool, not content), the OG
# image endpoint, any API routes, and the raw data files. The /data/
# JSON is an app fetch target, not a public-facing document — it carries
# no license/attribution metadata, so we don't want crawlers indexing or
# advertising it as free-to-grab. Listing the rest would dilute the
# topical signal without helping users.

User-agent: *
Allow: /
Disallow: /me/
Disallow: /u/
Disallow: /compose/
Disallow: /custom/
Disallow: /api/
Disallow: /og.png
Disallow: /data/

Sitemap: https://legible-markets.vercel.app/sitemap-index.xml
Sitemap: https://legible-markets.vercel.app/sitemap-sources.xml
